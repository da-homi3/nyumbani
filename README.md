# Nyumbani

Monorepo for **NyumbaSearch** — Kenya rental property search.

| Path | Description |
|------|-------------|
| [`find-nyumba-smart/`](find-nyumba-smart/) | TanStack Start app (React 19, Supabase, Cloudflare Workers) |
| [`supabase/migrations/`](supabase/migrations/) | Shared Postgres schema and RLS migrations |

## Clone

```bash
git clone --recurse-submodules https://github.com/da-homi3/nyumbani.git
cd nyumbani/find-nyumba-smart
npm install
```

## App development

See [find-nyumba-smart/README.md](find-nyumba-smart/README.md) for setup, environment variables, migrations, testing, and deployment.
